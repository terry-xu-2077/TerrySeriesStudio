# TerrySeriesStudio · 剧集工作室

**AI 辅助剧本与分镜创作 + 本地 ComfyUI 视频生成的一体化剧集生产工作台。**

> 状态：产品规划 / 尚未开始实现 · 2026-10-20

## 产品目标

以“完成一集剧”为基本生产单位，把 **剧本 → AI 批改与改写 → 人工批准 → 分镜脚本 → AI 批改与改写 → 人工批准 → 本地视频生成 → 审片与局部返工 → 分镜素材交付** 连成可追溯、可恢复的闭环。

主要目标是减少创作者在剧本改写、镜头拆解、资产绑定、提示词整理、任务排队和返工管理上的重复劳动，**保留人对剧情与镜头的最终决定权**。

- **创作**：剧本、分镜脚本、审核与改写通过可配置的云端 LLM / 多模态 API。
- **生成**：通过 HTTP / WebSocket 接入用户已有的 ComfyUI，使用 ComfyUI 自己的 Python 推理环境；首个验收环境为 RTX 3090 + MiniMax H3。
- **资产管理**：项目级角色与场景档案；角色包含多张形象图、声音样本/音色、人物文本设定，场景包含多张环境图、空间描述和可选环境音；跨集复用并绑定到剧本、分镜和生成任务。
- **连续性**：工作台管理镜头/片段之间的生成上下文、尾帧参考、续接和重叠条件，并追踪上下文过期。
- **交付**：保存和审查独立视频片段及其参数、版本和依赖；输出可供后期剪辑使用的素材清单。
- **明确边界**：不做 NLE 剪辑、字幕轨、转场、混音、调色或成片包装；不重写 ComfyUI 的推理引擎。

## 第一阶段使用场景

以《异星边境》第一季 **EP01** 为端到端验收目标。现有人物资产可复用；项目设定、剧本、其他场景资产作为导入数据，不与原内容仓库建立写入耦合。

在基础链路验证以前，不追求多用户、插件市场、商业 SaaS 或复杂的通用自动化平台。

## 三个主工作区

1. **剧本**：编辑、AI 独立审查、定向改写、版本对比、人工批准。
2. **分镜**：把批准的剧本转为结构化场景/镜头、AI 导演审查、资产引用、人工批准。
3. **生成**：把批准的镜头映射为生成片段、管理上下文衔接、提交 ComfyUI 队列、审片与重跑。

项目 / 剧季 / 剧集和资产库贯穿三个工作区，所有版本、任务和结果使用同一份项目数据。

不直接搬运旧仓库的整套业务层或 UI。先定义新产品的数据契约，再按需复用经过验证的能力与设计。

## 技术方向（待实现）

- **界面**：React + TypeScript，优先本地浏览器访问。
- **本地控制服务**：Node.js + TypeScript，负责云端 AI API、安全保存凭据、项目持久化及无人值守任务调度；**不另建 Python 后端或 Python 环境**。
- **数据**：SQLite（元数据、审核记录、快照与队列）；大媒体保存在文件系统。
- **AI**：可配置 API Provider / Model Profile；剧本创作、独立审稿和分镜导演共用统一调用与用量记录。
- **ComfyUI**：HTTP 提交任务 + WebSocket / 历史接口追踪结果；工作流本体和 GPU 推理仍由独立的 ComfyUI 管理。
- **环境**：Windows 本机优先；启动轻量 Node.js 常驻服务、浏览器访问；ComfyUI 独立运行，互不接管启停。不要求第一版封装 Tauri/Electron 桌面程序。
